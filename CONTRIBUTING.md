# Contributing

Technical coordination stays in public GitHub issues and the public WarriorHacks Discord channel.

Code pairing, pull request review, and mentoring that include a minor happen in a public channel or a video room with at least two adults present. Do not open a one-to-one private message with a minor on Discord, Devpost, or GitHub.

Do not commit API keys, tokens, or credential files. Keys belong in the environment or a secret store, not in git.
